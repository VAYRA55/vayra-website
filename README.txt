VAYRA PREMIUM WEBSITE — STARTER
================================

This is a custom HTML/CSS/JavaScript storefront. No Shopify.

FILES
- index.html
- style.css
- script.js

HOW TO TEST
1. Open index.html in a browser.
2. The site works as a front-end demo.
3. Product/cart data is stored in the browser.

WHATSAPP
Open script.js and replace:
WHATSAPP_NUMBER = "91XXXXXXXXXX"
with your real WhatsApp number, including country code and without +.

IMPORTANT
- Prices/products are demo content.
- Checkout currently opens WhatsApp; there is no real payment gateway.
- For real online payments, connect a payment provider and a backend/order database.
- Replace the CSS mockup product visuals with your actual product photos before launch.
- For free hosting, GitHub Pages or Cloudflare Pages can be used.
